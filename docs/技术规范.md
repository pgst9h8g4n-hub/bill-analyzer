# 小六记 - 技术规范

## 技术栈选型

### 前端
- **框架**：SvelteKit 4.x
- **构建工具**：Vite 5.x
- **状态管理**：Svelte store（内置）
- **样式**：Tailwind CSS 3.x + DaisyUI
- **图表**：Apache ECharts 5.x（支持穿透交互）
- **PWA支持**：svelte-pwa 或 Vite PWA 插件

### OCR方案
- **触发方式**：iOS快捷指令（Shortcuts）
- **识别引擎**：Apple Vision Framework（系统内置）
- **数据传递**：通过URL Scheme或Share Extension将OCR结果传递给PWA
- **优势**：免费、速度快、离线可用、隐私安全

### 数据存储
- **本地**：IndexedDB（通过 Dexie.js 封装）
- **加密**：本地敏感数据使用 AES 加密存储
- **备份**：支持导出 JSON/CSV 手动备份

### 认证方案
- **方式**：本地账号密码
- **密码存储**：bcrypt 哈希（前端本地验证，不做服务端认证）
- **会话管理**：IndexedDB 存储 Token

## 关键技术方案

### 1. iOS快捷指令 + PWA集成

```swift
// 快捷指令伪代码
let image = PhotosPicker.sharedPhotoPickerResult()
let ocrResult = try await image.textRecognizer.recognizeText(image)
let expense = Expense(
    amount: ocrResult.extractAmount(),
    time: ocrResult.extractTime(),
    merchant: ocrResult.extractMerchant()
)
open URL("xiaoliuji://add-expense?data=\(expense.json)")
```

### 2. IndexedDB 数据结构

```typescript
// Dexie.js 定义
class ExpenseDatabase extends Dexie {
  expenses: Table<Expense, number>;
  categories: Table<Category, number>;
  users: Table<User, number>;
  budgets: Table<Budget, number>;

  constructor() {
    super('XiaoLiujiDB');
    this.version(1).stores({
      expenses: '++id, userId, paidAt, amount, category',
      categories: '++id, name, isDefault',
      users: '++id, username',
      budgets: '++id, userId, month'
    });
  }
}
```

### 3. 图表穿透交互

```typescript
// ECharts 配置示例
const chartOption = {
  series: [{
    type: 'pie',
    data: expenseByCategory,
    emphasis: {
      itemStyle: {
        shadowBlur: 10,
        shadowOffsetX: 0,
        shadowColor: 'rgba(0, 0, 0, 0.5)'
      }
    }
  }],
  // 点击事件触发路由跳转
  onClick: (params) => {
    navigateTo(`/expenses?category=${params.name}`)
  }
};
```

## 编码规范

- 使用 TypeScript 严格模式
- 组件采用组合式 API 风格
- 所有 API 调用使用 try-catch 包裹
- 错误提示使用中文
- 遵守 ESLint + Prettier 配置

## 部署方案

- **平台**：Vercel / Cloudflare Pages / Railway
- **域名**：自定义域名或平台默认域名
- **HTTPS**：必须启用（PWA要求）
- **离线支持**：Service Worker 缓存关键资源
