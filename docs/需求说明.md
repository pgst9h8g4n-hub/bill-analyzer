# 小六记 - 需求说明

## 项目概述

每日消费记账应用，通过截图自动识别消费信息，帮助用户便捷记录和管理日常支出。

**运行环境**：iPhone 16，PWA网页应用（通过Safari添加到主屏幕使用）

---

## 核心功能列表

### 优先级 P0（必须实现）

| 功能 | 描述 |
|------|------|
| 截图识别记账 | 用户付款后截图，通过iOS快捷指令触发系统OCR，自动提取时间、金额、商户信息 |
| 消费记录管理 | 查看、编辑、删除消费记录 |
| 多记账人支持 | 支持多个记账人，区分不同家庭成员的账单 |
| 本地认证 | 简单的用户名+密码登录，数据本地存储 |
| 基础统计 | 按时间周期（日/周/月）、分类、记账人维度统计支出 |
| 消费分类 | 预设常用分类（餐饮、交通、购物等），支持用户自定义 |
| 穿透图表 | 点击图表可下钻到具体消费明细 |
| 数据导出 | 支持Excel和CSV格式导出 |

### 优先级 P1（重要但可延后）

| 功能 | 描述 |
|------|------|
| 月度预算提醒 | 设置月度消费上限，超支时提醒 |
| 图表分析 | 更丰富的可视化图表 |
| 批量导入 | 支持手动批量录入 |

### 优先级 P2（后期扩展）

| 功能 | 描述 |
|------|------|
| 云端同步 | 多设备数据同步 |
| 多人共享账本 | 家庭成员共享同一个账本 |
| 消费趋势分析 | 环比/同比分析 |

---

## 技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端框架 | SvelteKit | 轻量、性能好，适合PWA |
| 构建工具 | Vite | 快速构建 |
| 样式 | Tailwind CSS | 原子化CSS，快速开发 |
| 图表 | Apache ECharts / Chart.js | 支持穿透交互 |
| OCR方案 | iOS快捷指令 + 系统Vision API | 免费、快速、隐私安全 |
| 数据存储 | IndexedDB（本地） | 前期纯本地存储 |
| 后端（可选） | FastAPI / Node.js | 如需云端同步再引入 |

---

## 数据模型（初步）

### 用户（User）
- id: 唯一标识
- username: 用户名
- password_hash: 密码哈希（本地加密存储）
- created_at: 创建时间

### 消费记录（Expense）
- id: 唯一标识
- user_id: 记账人ID
- amount: 金额
- category: 消费类型
- merchant: 商户名称（OCR识别）
- remark: 备注
- screenshot_url: 截图路径（可选）
- created_at: 记录时间
- paid_at: 消费时间

### 消费分类（Category）
- id: 唯一标识
- name: 分类名称
- icon: 图标
- is_default: 是否预设分类
- color: 颜色标记

### 预算（Budget）
- id: 唯一标识
- user_id: 用户ID
- month: 月份（YYYY-MM）
- limit: 预算上限
- category_id: 关联分类（可为空，表示总预算）

---

## 用户流程图

```
用户付款 → 截图 → 快捷指令触发 → iOS系统OCR识别 → 
提取金额、时间、商户 → 填充表单 → 选择分类/记账人 → 确认保存 → 
数据存入IndexedDB → 更新统计图表
```
