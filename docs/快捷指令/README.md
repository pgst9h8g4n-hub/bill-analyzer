# 小六记 — iOS 快捷指令

## 简介

使用 iOS 快捷指令（Shortcuts）实现「相册选图 → 系统 OCR 识别 → 打开 PWA 预填表单」的完整记账流程。

---

## 使用方法

### 方式一：直接导入 Swift 脚本（推荐）

1. 打开 `/Docs/快捷指令/OCR记账.swift`
2. 将 `BASE_URL` 替换为你实际部署的地址（如 `https://xiaoliuji.vercel.app`）
3. 在 iPhone 上通过「文件」App 打开 `.swift` 文件
4. 点击分享按钮 → 选择「快捷指令」
5. 完成导入后，在快捷指令 App 中添加相册权限
6. 运行快捷指令即可

### 方式二：手动创建快捷指令（无需编写代码）

1. 打开「快捷指令」App → 新建快捷指令
2. 添加动作：**选择照片**（从相册中选一张）
3. 添加动作：**获取图像数据**
4. 添加动作：**识别文字**（使用「文本」→「识别文本」）
5. 添加动作：**查找文本**（正则匹配金额 `¥(\d+\.\d+)`）
6. 添加动作：**查找文本**（获取商户名，取第一行中文）
7. 添加动作：**打开 URL**，格式：
   ```
   https://你的域名/ocr?amount={金额}&merchant={商户}
   ```
8. 保存并添加到主屏幕

---

## URL 参数说明

快捷指令会将识别结果拼接到 URL 参数中，PWA 自动读取并预填表单：

| 参数 | 说明 | 示例 |
|------|------|------|
| `amount` | 金额（元） | `amount=25.50` |
| `merchant` | 商户名称 | `merchant=星巴克` |
| `time` | 时间（可选） | `time=2026-08-25T14:30` |

---

## 部署前必做

在打开 `OCR记账.swift` 之前，务必将 `BASE_URL` 改为你的实际部署地址：

```swift
// 修改这一行
let BASE_URL = "https://your-app.vercel.app"
// 改为你的地址，例如：
let BASE_URL = "https://xiaoliuji.vercel.app"
```

---

## 注意事项

- 快捷指令需要相册访问权限，首次运行会弹出授权提示
- OCR 识别结果取决于照片清晰度，建议拍摄付款凭证正面
- 识别到的金额和商户会在 PWA 表单中预填，用户可手动修改后确认保存
